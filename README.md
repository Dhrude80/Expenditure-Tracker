# Expenditure-Tracker
This is a project in which the user can record and manage their daily expenditures. The program helps keep track of spending by allowing the user to add, view, edit, and remove expense entries. This is one of my beginner projects which I built to understand the concepts of dictionaries, loops, conditionals, and basic record management in Python.

Features :

Add expenditure entries.
View saved expenditures.
Edit existing expenditure records.
Remove expenditure records.
Simple and clean UI.
Fast execution.

How to Run :

Run the program.
Choose the required option from the menu.
Enter the expenditure details when prompted.
View, edit, or remove records as needed.

Requirements : Python 3.x Jupyter Notebook

AI use : Used for improving project idea, fixing logic errors, and understanding some Python concepts
